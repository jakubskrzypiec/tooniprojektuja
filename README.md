# To Oni Projektują — landing page

Gotowa, statyczna strona do publikacji między innymi przez GitHub Pages.

- `index.html` — główny wariant strony.
- `wariant-b.html` — porównawczy wariant B galerii, kontaktu i dolnego pasa marki.
- `about-cats-temporary.webp` — robocze zdjęcie kotów w sekcji „O nas”; można je później podmienić bez zmian w kodzie, zachowując tę samą nazwę pliku.
- Lokalne fonty Gill Sans MT i ISOCTEUR znajdują się w katalogu `fonts`.
- Formularz wysyła wiadomości na `tooniprojektuja@gmail.com` przez FormSubmit. Po pierwszej próbie wysłania należy jednorazowo potwierdzić aktywację formularza z wiadomości otrzymanej na ten adres.
- Drugi numer telefonu pozostawiono jako „Wkrótce”, ponieważ nie został podany w materiałach.

Strona nie wymaga procesu budowania ani instalowania zależności. Wystarczy opublikować cały katalog, zachowując strukturę plików.
